About This System

This application uses Long Short-Term Memory (LSTM) Deep Learning Neural Networks to forecast stock prices based on historical financial time series data.

Key Features:
  • Real-time financial data fetching via Yahoo Finance API
  • Deep Learning LSTM architecture with Dropout & Early Stopping
  • Comprehensive metrics: RMSE, MAE, MAPE, R-squared, and Directional Accuracy
  • High-resolution visualization of past prices and future forecasts
  • Multi-day business forecasting up to 30 days ahead
